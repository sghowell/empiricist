# P5: the 2D cluster family — a new exact value on the marquee open target

**Date:** 2026-07-10 · **Problem:** P5(ii), the L×M 2D cluster-state family
("even the 2D cluster family is open") · **Method:** beyond-frontier model search +
two-engine verification. Focused live spend ≈ $17 (two dedicated generations).

The 2D cluster state on an L×M grid is the physically central open case in P5(ii).
This run establishes a new exact value and grounds the family conjecture.

## Results (all independently re-verified from scratch)

| cluster | N | `F(G)` | source |
|---|---|---|---|
| 2×2 (= C₄) | 4 | **1 = N−3** | exact table (Tier-0; C₄ is LC-equiv to a tree) |
| 2×3 | 6 | **6 = N** | exact table (Tier-1) |
| **2×4** | 8 | **8 = N** | **model search + two-engine witness (this run)** |
| 3×3 | 9 | `F ≥ 9 = N` (open) | conjectured N; not cracked in 32 focused attempts |

**The 2×4 closure (the new result).** The 2×4 cluster was an *open* orbit in the
M5c/live tablebase (`F ≥ 8`, Tier-1 never run at n=8). The model proposed an
8-resource, 8-fusion, 1-LC construction; **independent re-verification** (a fresh
`verify_agreed` from the CAS witness) confirms `PASS`, **both fusion engines (stim ∧
GF(2)) agree**, the size identity holds (`8 = 3·8 − 2·8`), and the achieved LC-orbit
is exactly the 2×4 cluster. With the universal `F ≥ N−3` lower bound + the L2 mod-3
ladder + Tier-1's exclusion of `F ≤ N−3` for this orbit, this pins **`F(2×4) = 8 =
N` exactly** — a value no deterministic tier in the project had reached.

## Conjecture (grounded, marquee)

> **`F(L×M cluster) = N` for every non-degenerate L×M grid (L,M ≥ 2, not both 2).**

Grounded on `2×3 = 6` (table) and `2×4 = 8` (this run's certified witness); the
degenerate `2×2 = C₄` is the sole `N−3` case (it is LC-equivalent to a tree). This
matches the physics intuition that cluster states are Tier-1 (one intra-fusion
beyond an all-merge backbone). It is a *conjecture*, not a theorem — the general L,M
proof is open, and it needs the fusion→graph semantics + an inductive backbone
argument to formalize.

## Honest limits

- **3×3 (n=9) is not closed** — an honest negative. **5 focused generations (160
  attempts)** across two rounds produced many valid F=9 constructions, but *none*
  landed the specific 3×3 grid orbit; the stochastic hit-rate on a single n=9 target
  is too low. It stays open at `F ≥ 9`, conjectured `= N`. Note the rank-width
  characterization does **not** settle it: the 3×3 cluster is not distance-hereditary
  (so `rw ≥ 2`, consistent with `F ≥ N`), but `rw=2` alone does not force `F=N` (see
  the refuted formula in `2026-07-12-p5-tier0-characterization.md`). A definitive
  resolution needs either a witness (harder search / better-guided prompt) or a
  targeted deterministic Tier-1 reachability check on just that orbit.
- Only the 2×L strip and 3×3 small cases are in reach; general L×M is past the
  enumeration frontier, so the family value rests on the conjecture + the two
  certified small cases, not exhaustive verification.
- This is model-assisted search where the *upper-bound witness* is machine-certified
  (two independent engines) but the *lower bound* for the open cases is Tier-0's
  `F ≥ N`; the exact value is pinned only where a witness meets a proven floor
  (2×4). The conjecture beyond that is honest extrapolation from grounded data.
