  > **UPDATE (soundness fix, supersedes the axiom-audit design above).** The in-band `#print axioms <decl>` approach is **UNSOUND**: it is an in-environment command the submitted source can **shadow**. Two adversarial reviews defeated it — (1) forging the `'<decl>' depends on axioms: [...]` info-diagnostic via `#eval IO.println` / `run_cmd Lean.logInfo`, and — fatally — (2) **redefining the `#print axioms` command itself** (`elab "#print " "axioms" ... => logInfo "...clean..."` or `macro_rules | `(#print axioms $n) => ...`), so the harness's own appended `#print axioms` dispatches to the attacker's elaborator and emits a fabricated clean line (nonce-anchored, exactly-one, whitelist-clean — full nonce-anchor hardening did NOT close it). Proven end-to-end: `theorem two : (1:Nat)=2 := evil.elim` (backed by `axiom evil : False`) certified as FORMALIZED. **Root cause:** any surface the harness re-elaborates in the tainted environment (`#print`, `#eval`, `run_cmd`, macros) is attacker-shadowable, so the axiom set MUST be computed by **compiled harness code** that walks the real kernel environment — never a re-elaboratable command. **Replacement (implemented):** a compiled `axiom_audit` `lean_exe` (`lean/EmpiricistLean/AxiomAudit.lean`) that elaborates the source with the real frontend (`Lean.Elab.runFrontend` under `IO.FS.withIsolatedStreams`) and computes the decl's axiom closure via compiled `Lean.collectAxioms` (exactly what `#print axioms` calls internally). It emits one nonce-framed JSON line (`AXIOM_AUDIT::<nonce>::{declFound,errors,axioms}`) to real stdout; the nonce is read from a file the driver deletes **before** elaborating the untrusted source, so compile-time IO cannot learn it and cannot forge an accepted line even via a direct `/dev/stdout` write + `IO.Process.exit`. `LeanVerifier.verify` runs `lake env <bin>/axiom_audit <scratch> <decl> <noncefile>` (same scrubbed env), parses the nonce-framed line as the SOLE axiom authority, and gates: errors → FAIL(diagnostics); `declFound` false → FAIL(decl_missing); axioms ⊄ whitelist → FAIL(axioms); no valid nonce line → FAIL(driver_result). `binary_hash` additionally covers `AxiomAudit.lean`. The must-FAIL golden suite adds the two command-override vectors + the driver-result output-injection vector (`verifiers/lean_goldens.py`). Verifier `version` bumped `1.0`→`2.0`.
