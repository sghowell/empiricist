### Task 1: diagrams and semantics

`diagram.py`: `Diagram` (frozen dataclass; vertices `{id: (kind, phase)}` with kind in `Z|X|B`, edges as a multiset of `(u, v, hadamard: bool)`, `inputs`/`outputs` as ordered boundary ids), `to_json`/`from_json` (canonical: sorted, phases as `"k/4"` strings), `relabel_canonical()` (a deterministic relabelling so isomorphic diagrams compare equal; a simple invariant-based refinement is enough at this size), `is_well_formed`. `semantics.py`: `matrix(diagram) -> np.ndarray` by tensor contraction of spider tensors (Z spider with phase α: all-zeros and all-ones entries 1 and e^{iα}; X = Hadamard-conjugated Z; Hadamard edge = H matrix), `equal_up_to_scalar(a, b, tol=1e-9)`. Tests: the Bell state, a CNOT built from two spiders, `H·H = I`, the π/4 phase gate, colour change invariance.

### Task 2: rules, matching, rewriting, derivations

`rules.py`, `rewrite.py`, `derivation.py` as in the architecture paragraph. Every rule is **semantics-checked in tests** on concrete instances (LHS and RHS evaluate to equal matrices up to scalar). Derivation replay returns the reached diagram and the first invalid step, if any.

### Task 3: the four verifiers, goldens, manifest

- `zx_derivation`: payload `{"start", "end", "steps": [{"rule", "matching", "direction"}]}`; PASS iff every step applies and the final diagram is canonically equal to `end`; FAIL with the offending step index otherwise.
- `zx_semantic_equal`: payload `{"a", "b"}`; PASS iff equal up to scalar; FAIL otherwise; ERROR above 6 boundary wires.
- `zx_critical_pairs`: payload `{"rules": [rule names or inline rules], "depth": k}`; PASS iff every critical pair is joinable within `k` steps; FAIL names the first non-joinable pair.
- `zx_termination`: payload `{"rules": [...], "measure": [component names]}`; PASS iff each rule strictly decreases the lexicographic measure on its LHS→RHS; FAIL names the rule.
- Goldens per verifier as required by the constraints; `MANIFEST`; `tests/test_packs_zx.py` certifies every verifier PASS in a temp repository (`certify_pack_verifier`) and checks each golden's verdict directly.
