**Goal:** A `zx` pack under `empiricist.packs.zx` that gives the harness everything it needs to attack Problem 6 (`docs/open_problems_ftfbqc.md`, §3 Problem 6) without any model spend in this milestone: a ZX-diagram model with a canonical JSON form, the Clifford and Clifford+T rewrite rules, and four certified pack verifiers with golden suites — derivation replay, small-size semantic equality, critical-pair joinability, and termination certificates. **Architecture:** `packs/zx/diagram.py` (open graphs: `Z`/`X` spiders with phases in `k·π/4` as `Fraction(k, 4)` mod 2, boundary vertices ordered as inputs/outputs, plain and Hadamard edges; a canonical JSON encoding and a canonical relabelling), `packs/zx/semantics.py` (numpy evaluation of a diagram to a `2^out × 2^in` matrix, exact enough for ≤ 6 boundary wires; equality up to a non-zero scalar), `packs/zx/rules.py` (rules as LHS/RHS diagram patterns with variable phases and variable-arity spiders where the rule needs them: spider fusion, identity removal, colour change, π-copy, state copy, bialgebra, Hopf, the Euler decomposition of Hadamard, and the Jeandel–Perdrix–Vilmart Clifford+T supplement — cite the paper's rule names), `packs/zx/rewrite.py` (a matching = injective map from LHS vertices to diagram vertices respecting types, phases, edges and boundary arity; `apply(diagram, rule, matching)`), `packs/zx/derivation.py` (a derivation = start diagram + `[(rule name, matching, direction)]` + claimed end; replay), `packs/zx/critical_pairs.py` (overlaps between two LHS's; joinability search bounded by depth `k`), `packs/zx/termination.py` (a measure certificate: a lexicographic tuple of counts the checker recomputes on every rule's LHS and RHS, PASS iff each rule strictly decreases it), `packs/zx/verifiers.py` (the four `PackVerifier`s), `packs/zx/goldens/` (payload files), `packs/zx/__init__.py` (`MANIFEST`, `problems={"P6": "p6-zx-v1"}`).

### Task 1: diagrams and semantics

`diagram.py`: `Diagram` (frozen dataclass; vertices `{id: (kind, phase)}` with kind in `Z|X|B`, edges as a multiset of `(u, v, hadamard: bool)`, `inputs`/`outputs` as ordered boundary ids), `to_json`/`from_json` (canonical: sorted, phases as `"k/4"` strings), `relabel_canonical()` (a deterministic relabelling so isomorphic diagrams compare equal; a simple invariant-based refinement is enough at this size), `is_well_formed`. `semantics.py`: `matrix(diagram) -> np.ndarray` by tensor contraction of spider tensors (Z spider with phase α: all-zeros and all-ones entries 1 and e^{iα}; X = Hadamard-conjugated Z; Hadamard edge = H matrix), `equal_up_to_scalar(a, b, tol=1e-9)`. Tests: the Bell state, a CNOT built from two spiders, `H·H = I`, the π/4 phase gate, colour change invariance.

### Task 2: rules, matching, rewriting, derivations

`rules.py`, `rewrite.py`, `derivation.py` as in the architecture paragraph. Every rule is **semantics-checked in tests** on concrete instances (LHS and RHS evaluate to equal matrices up to scalar). Derivation replay returns the reached diagram and the first invalid step, if any.

### Task 3: the four verifiers, goldens, manifest

- `zx_derivation`: payload `{"start", "end", "steps": [{"rule", "matching", "direction"}]}`; PASS iff every step applies and the final diagram is canonically equal to `end`; FAIL with the offending step index otherwise.
- `zx_semantic_equal`: payload `{"a", "b"}`; PASS iff equal up to scalar; FAIL otherwise; ERROR above 6 boundary wires.
- `zx_critical_pairs`: payload `{"rules": [rule names or inline rules], "depth": k}`; PASS iff every critical pair is joinable within `k` steps; FAIL names the first non-joinable pair.
- `zx_termination`: payload `{"rules": [...], "measure": [component names]}`; PASS iff each rule strictly decreases the lexicographic measure on its LHS→RHS; FAIL names the rule.
- Goldens per verifier as required by the constraints; `MANIFEST`; `tests/test_packs_zx.py` certifies every verifier PASS in a temp repository (`certify_pack_verifier`) and checks each golden's verdict directly.

### What exists

`src/empiricist/packs/zx/`:

- `diagram.py` — `Diagram`: open multigraph of `Z`/`X`/`B` vertices, phases in units of pi
  (`Fraction` mod 2, or a linear `PhaseExpr` over named variables for patterns and symbolic
  hosts), plain and Hadamard edges as a multiset (self-loops and parallel edges allowed),
  ordered inputs/outputs; canonical JSON (`{"vertices": [[id, kind, phase]], "edges":
  [[u, v, hadamard]], "inputs", "outputs"}`, phases as reduced fraction strings);
  `well_formedness_problems`; `relabel_canonical` by colour refinement plus
  individualisation (boundary vertices fixed by position), `isomorphic`.
- `semantics.py` — `matrix(d)`: the `2^out x 2^in` matrix by greedy pairwise tensor
  contraction of spider tensors (Z: 1 at 0...0, e^{i pi a} at 1...1; X: Z with a Hadamard
  on every leg; Hadamard edge: H; boundary vertex: identity); self-loops are traces;
  budgets (6 boundary wires, 64 vertices, degree 16, 20 open indices) raise
  `SemanticsError`; `equal_up_to_scalar` by projection with tolerance 1e-9 (both-zero is
  equal, one-zero is not).
- `rules.py` — `Rule(name, lhs, rhs, residual, reference)`: patterns over a shared
  interface; `residual` marks star (variable-arity) vertices and where their extra legs go,
  with a Hadamard flip per target; `reversed()`; JSON form; the library `RULES` (table
  below), `CLIFFORD_RULES`, `CLIFFORD_T_RULES`, `rule_table()`.
- `rewrite.py` — `Matching(vertices, phases, split)`, `check_matching` (injective on
  spiders, kinds, the identification condition for interface images, edge counting per
  signature, non-star degree exactness, phase solving for unit-coefficient variables and
  syntactic equality otherwise), `apply` (delete the spider image and matched edges, add
  the RHS with fresh ids, re-attach residual legs with per-end flips), `find_matchings`
  (backtracking), `successors`.
- `derivation.py` — `Step(rule, matching, direction)`, `Derivation(start, steps, end)`,
  `replay` -> reached diagram, first failing step and reason, end equality.
- `critical_pairs.py` — `overlaps(r1, r2)`: every gluing of L2 onto L1 (spider-spider
  and spider-onto-context identification, edge identification or fresh edges at star
  vertices, symbolic phase unification with a ground fallback), context legs on star
  vertices up to `star_legs` per star, criticality by a shared deleted spider or edge,
  dedup by canonical forms; `joinable(a, b, rules, depth)`: bidirectional bounded BFS over
  canonical forms in the forward direction, retried on every ground instance of the
  pair's variables when the symbolic search fails; `check(rules, depth)`.
- `termination.py` — lexicographic measures over local counts (`vertices`, `z_vertices`,
  `x_vertices`, `edges`, `hadamard_edges`, `plain_edges`, `self_loops`) evaluated
  symbolically per rule including every residual-leg category and target choice.
- `verifiers.py`, `goldens/` (20 payloads), `__init__.py` (`MANIFEST`: `zx` 0.1, four
  verifiers, `problems={"P6": "p6-zx-v1"}`).

### Verifier contracts as implemented

All four are `BytesFileVerifier`s, version `1`, `binary_hash = module_source_hash(verifiers,
<engines>)` with the engines listed per verifier; `verify_bytes` is total; ERROR means "could
not judge" (malformed JSON or schema, ill-formed diagram, unknown rule or component, budget
exhausted), never a verdict on the claim.

- `zx_derivation` (engines diagram, rules, rewrite, derivation). Payload `{"start", "end",
  "steps": [{"rule", "matching": {"vertices": {lhs id: host id}, "phases"?, "split"?},
  "direction": "->"|"<-"}], "rules"?: [inline rules]}`. PASS iff every step applies in order
  and the reached diagram is canonically equal (isomorphic with boundary order) to `end`;
  FAIL with `failed_step` and `reason` (first step that does not apply), or `failed_step:
  null` with `reason: "end mismatch"` and the reached diagram. Rule names resolve in the
  library; inline rules may add names but not shadow library names (ERROR).
- `zx_semantic_equal` (engines diagram, semantics). Payload `{"a", "b"}`. FAIL if the wire
  counts differ; otherwise PASS iff `equal_up_to_scalar(matrix(a), matrix(b), 1e-9)`; ERROR
  above the budget (6 boundary wires, 64 vertices, degree 16, 20 open indices).
- `zx_critical_pairs` (engines diagram, rules, rewrite, critical_pairs). Payload `{"rules":
  [names or inline rules], "depth": 0..12, "star_legs"?: 0..3 (default 1), "fragment"?:
  "clifford+t"|"clifford" (phase set for case splits), "max_nodes"?, "max_instances"?}`.
  PASS iff every enumerated critical pair of the oriented rules is joinable within `depth`
  forward steps on each side (details: pairs, overlaps, case_splits); FAIL names `rule1`,
  `rule2`, the reason (including the failing ground instance) and the overlap with both
  results; ERROR when a search budget runs out.
- `zx_termination` (engines diagram, rules, termination). Payload `{"rules": [...],
  "measure": [component names]}`. PASS iff every rule strictly decreases the lexicographic
  measure on every instance (components weakly decreasing for every residual-leg category
  up to and including the first strictly decreasing one); FAIL names the `rule`, the
  `component` and why; ERROR on an unknown or empty component list.

Goldens (PASS / near-miss FAIL): derivation — fuse-then-identity, Euler there and back,
CNOT.CNOT = identity in five steps / one wrong vertex in step 2, the end off by one
phase, the last step missing; semantic — CNOT in two forms, H = Euler chain, a bialgebra
instance / the Euler chain with one phase sign flipped, T against T-dagger, CNOT with
control and target swapped; critical pairs — {fusion, identity_z} depth 1, {fusion,
fusion_x, colour_change} depth 2 / {fusion_x, colour_change} depth 2 (exactly one
non-joinable pair; adding fusion fixes it), the confluent set at depth 1 (one short);
termination — ten core rules under (vertices, edges), four Hadamard rules under
(hadamard_edges) / the core plus colour_change (ties), {fusion, hopf} under (vertices) (one
component short).

### What the first scientific target still needs from the pack

A completed stabilizer system (Problem 6 (ii)(a)) is a finite set of oriented rules that
is sound, terminating, locally confluent and complete for stabilizer diagrams. The pack
now certifies pieces of that; the honest gaps:

1. **The critical-pair lemma for star rules is not established.** `zx_critical_pairs`
   enumerates residual-leg configurations up to `star_legs` per star vertex, so a PASS is
   local confluence at bounded arity, not for every host. A completed system needs either
   a proof that joinability of its critical pairs does not depend on the number of
   residual legs (for instance because every joining derivation touches star images only
   through star rules) or a proper !-box overlap theory; neither is in the pack.
2. **Rule soundness is not certified.** The two system-level verifiers judge properties of
   the rules as given; a candidate system's rules need a soundness certificate. The
   semantic oracle covers ground instances on <= 6 wires; a rule-soundness verifier over
   phase variables (ground over the 4 stabilizer phases, with bounded extra legs on
   stars) is a small addition, not yet made.
3. **Completeness is not checked.** Terminating plus locally confluent gives unique normal
   forms; completeness for the fragment further needs semantically equal diagrams to
   share a normal form. That needs an enumerator of small stabilizer diagrams, reduction
   to normal form and comparison against the semantic oracle; none exists.
4. **Termination measures are structural only.** Lexicographic local counts cannot orient
   colour change (it ties on every offered component) or any rule whose effect is on
   phases; polynomial interpretations, phase-aware components or a graph-like
   normalisation (eliminate X first, then a Z-only measure) are needed and not built.
5. **Symbolic phases match syntactically.** A rule with a constant phase never matches a
   symbolic vertex; the ground case split is sound but costs |phases|^variables per pair,
   and a candidate system will in practice be phase-indexed (finitely many instances per
   schema), which the inline-rule payload supports but the library does not pre-build.
6. **Scalars.** Everything is up to non-zero scalar (zero diagrams are equal only to zero);
   an exact-scalar treatment (JPV's scalar sub-diagrams) is not modelled.
7. **The rewriting relation is the pack's own.** Interface images may coincide and may
   land on boundary vertices or spiders but never on a deleted spider (identification
   condition); non-star vertices match degree-exactly; a self-loop is not an identity
   match. A confluence claim is a claim about this relation; the mapping to the standard
   presentation (DPO on open graphs with !-boxes) should be written down before a
   confluence proof is formalised.
8. **Joinability is a bounded BFS.** For a terminating candidate, comparing normal forms
   would replace the search and scale far better; not implemented. Depth-5 surveys of a
   24-rule set take minutes; the verifier's per-pair node budget is the only guard.
9. **No search, no campaign.** Knuth-Bendix-style completion, candidate generation, the
   P6 claim/move/playbook wiring and the problem document `p6-zx-v1` itself are not in
   this milestone; the manifest only reserves the version string.
10. **Canonical forms without automorphism pruning** (individualisation-refinement, budget
    20000 leaves): a highly symmetric diagram would make a verifier ERROR rather than
    answer. Not hit in any test or survey.
11. **No third-party cross-check.** `pyzx` is not installed and no dependency was added,
    so the semantic oracle is cross-checked only against hand-computed matrices (Bell,
    CNOT, H.H, T, colour change) and the library rules against each other.
