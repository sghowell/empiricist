# Papers

## Distance-hereditary graphs characterize minimum-fusion synthesis of graph states

`arxiv/` holds the arXiv submission: `main.tex` (revtex4-2), `refs.bib`, `main.bbl`, `main.pdf`, the
ancillary files `anc/` (Lean development, certified tablebase, re-derivation scripts with their
outputs; `anc/README.md` maps every claim to a file), the upload bundle `arxiv_source.tar.gz`, the
build script `build.sh` (tectonic, TeX Live pdflatex + bibtex, bundle, isolated rebuild), the
submission sheet `ARXIV_SUBMISSION.md`, and `reviews/` (Codex reviews and the fixes applied).

The July 2026 draft (`paper.tex`, removed in M27a) is in the git history; the arXiv version
supersedes it: it adds the rank-width bound F >= n + 3 rw - 6 with a written proof that closes the
draft's one unformalized step, places the result against the 2025-2026 literature, and corrects the
count of exact values above the minimum (19) and the rank-width of the six-vertex orbit with F = 9 (2).
