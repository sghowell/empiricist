# Primary-source and hypothesis dictionary

Sources checked on 2026-09-05; versions are deliberate.

[Fewster and Kontou, *A semiclassical singularity theorem*,
arXiv:2108.12668v1](https://arxiv.org/pdf/2108.12668v1) supplies the local-QSEI,
partition and timelike-focusing framework. Its quantitative application is a toy
scalar cosmology. In particular, the valid local averaging duration is an
additional assumption, not a calculated curved-spacetime error bound.

| Source location | Use here and retained limitation |

| Section 1 conventions | Signature (+---), negative Ricci contraction for timelike convergence; full expansion trace K |
| Definition 2.1; Section 3 | Semiclassical Einstein--Klein--Gordon, Hadamard state and fixed renormalization setup, only for the optional field interpretation |
| Equation (24) | Four-dimensional second-derivative coefficient; independently converted with the Einstein coupling |
| Definition 3.1; Eq. (29) | Local-duration/T-regularity assumption is retained explicitly |
| Definition 3.2; Proposition 3.3 | Wick-square restriction and consequent geometric bound; not an unrestricted state-independent Ricci inequality |
| Equations (46)--(55) | Index-form focusing architecture and cubic beta trial; replayed with a different exact partition functional |

The polynomial-angle H2 partition, exact geometric-tail Gram matrix and
two-parameter minimization in this checkpoint are derived in
[focusing.md](focusing.md), not reported as results quoted from that paper.

[Graf, Kontou, Ohanyan and Schinnerl, *Hawking-type singularity theorems for
worldvolume energy inequalities*, arXiv:2209.04347v3](https://arxiv.org/pdf/2209.04347v3)
is a separate potential continuation. This February 2026 version uses a
worldvolume-averaged condition with an additional global timelike Ricci bound;
its curvature convention makes timelike convergence nonnegative. It does not
replace the local worldline hypothesis in the present certificate. No equation
from its worldvolume theorem is used in our replay.
